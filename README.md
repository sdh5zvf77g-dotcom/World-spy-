# Unsealed

## Put it on your iPhone (about 3 minutes)
1. On github.com, create a new public repository named `unsealed`.
2. Upload every file in this folder to it (index.html, manifest.json, sw.js, and the three icon PNGs).
3. In the repository, open Settings > Pages. Under Branch choose `main` and `/ (root)`, then Save.
4. After a minute your app is live at `https://YOUR-USERNAME.github.io/unsealed/`.
5. Open that link in Safari on your iPhone, tap Share, then Add to Home Screen.

It refreshes each time you open it, and the Refresh button checks again on demand.
